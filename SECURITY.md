# Security Policy

## Supported versions

Reelspace is pre-release software. Security fixes are applied only to the newest published alpha; older builds are unsupported.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/canikou/Reelspace/security/advisories/new) for issues that could expose or delete local files, escape managed-folder boundaries, execute untrusted content, disclose sensitive diagnostics, or corrupt persistent user data.

For ordinary crashes and functional bugs, use the public issue tracker instead. Never upload personal recordings, a complete database, an unreviewed library-data export, full media paths, secrets, or other people's information. A minimal sanitized reproduction is preferred.

There is no hosted crash-report collection service. Reports are sent only when a user chooses to share them.
