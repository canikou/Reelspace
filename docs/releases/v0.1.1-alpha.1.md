# Reelspace v0.1.1-alpha.1

This is Reelspace's first public Windows alpha. It is intended for testing with backed-up gameplay recording libraries.

## Highlights

- Fast incremental indexing with persistent media probe caching
- Background thumbnail generation that resumes safely after interruption
- Local tags, notes, collections, playback, trimming, and clip generation
- Metadata-only library export/import for moving user organization without copying video
- Structured errors, bounded diagnostics, database integrity recovery, and safer filesystem handling

## Install

Download `Reelspace_0.1.1-alpha.1_windows_x64_setup.exe` and the matching `.sha256` file below. This installer is not code-signed, so Windows may display an unknown-publisher warning. Verify the SHA-256 value before running it.

Windows 10/11 x64 and WebView2 are required.

## Alpha limitations

- Keep backups of important recordings and exported library data.
- No automatic updater, cloud sync, hosted crash collection, or online archival is included.
- Import transfers organization metadata and file references, not media files or application settings.
- Review generated clips before deleting any raw source recording.

Report reproducible bugs through [GitHub Issues](https://github.com/canikou/Reelspace/issues). Remove personal paths and media from logs or screenshots before sharing them.
