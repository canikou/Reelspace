# Reelspace v0.4.0-alpha.1

Changes from the first days of using Reelspace as the recorder on Linux.

## Highlights

- **In-app preview works on Linux.** WebKitGTK can't stream video from custom URL schemes, so media now comes from a small server that only listens on this computer (127.0.0.1). It uses a per-launch token, supports seeking, and serves only files from your library folders.
- **Recorder toggle in the header.** Turn the recorder on or off, pick a mode (Game sessions, Rolling archive, Manual clips only) and save a clip from any page.
- **New Settings layout.** A category sidebar on the left and one scrolling list of options on the right. One Save bar shows when you have unsaved changes.
- **Storage budget.** Set a maximum size for full recordings in Settings → Recorder. When recordings go over it, the oldest full recordings are deleted first. Clips are never deleted automatically, and the free-space floor still applies.
- **The recorder's folder joins the library automatically.** Rolling chunks and game sessions appear as recordings, dated from their file names. Saved clips appear under Clips, with the game filled in.
- **Home** now uses the full window width.
