# Reelspace v0.3.0-alpha.1

This alpha makes Reelspace a recorder on Linux, not only a library. It includes a background recorder service, recording controls in the app, and GNOME on-screen notices. Windows gets the same library app as 0.2 plus fixes.

## Highlights

- **Background recorder (Linux).** `reelspace-recorder` runs as a systemd user service and records with gpu-screen-recorder. Three modes:
  - **Full session:** detects when a game launches and records the whole session.
  - **Manual clips only:** keeps a replay buffer and saves clips on demand.
  - **Always-on rolling archive:** records continuously in chunks, capped by size.
- **Safety:**
  - A hard free-disk floor (50 GB by default, never below 5 GB).
  - The size cap only ever deletes `rec_*.mkv` files.
  - Crash recovery for interrupted recordings.
  - Refuses to run alongside another capture.
  - Waits quietly while the display is off or the audio source is missing.
- **Settings → Recorder.** Every recorder option can be edited, alongside live status, Save clip, Pause/Resume, "Delete old rolling archive", and an explicit "Enable background recorder" button. The service is never enabled automatically.
- **Tray icon (Linux).** Save clip, Pause/Resume, Open library and Quit.
- **Clips.**
  - Saved as faststart MP4 with game metadata.
  - Notifications have Open and Show in folder actions.
  - Shutter and completion sounds.
  - A D-Bus API and `reelspace-recorder save-clip` for hotkeys (see `docs/recorder-dbus.md`).
- **GNOME Shell extension** (shipped in the deb and rpm). Shows on-screen notices over fullscreen games for clip saving and saved, session start, and pause and resume.
- **Replay buffer storage** can be disk (the default, which saves RAM) or memory.

## Notes

- The recorder needs `gpu-screen-recorder` and `gsr-cli`. It is tested on GNOME on Wayland with NVIDIA.
- The recorder binary, systemd unit and GNOME extension ship in the deb, rpm and Arch packages. The AppImage and the Windows builds contain only the library app.
- Back up important recordings while the project is in alpha.
